# ADR 0008: Verified Citation Corpus with Expected-References Evaluation

## Status
Accepted

## Context
Legal citations must be traceable to official sources. The single-file `CO.json`
corpus mixed topics, had no verification date, and the evaluation only measured
HIGH risk precision/recall with `legal_basis` always empty. The UI rendered
references as plain text, so users could not open or verify the cited norm.

## Decision
1. **Versioned multi-file corpus:** `backend/data/legal/manifest.json` (version 1)
   lists one JSON file per legal domain (`CO-ARRIENDO.json` 10 provisions,
   `CO-CONSUMO.json` 10 provisions). Each item validates against a strict Zod
   schema: `id, jurisdiction, sourceName, sourceUrl, reference, text, tema,
   vigenciaDesde, fuenteVerificadaEn`. Loader rejects unknown fields, duplicate
   ids, tema mismatches, and non-CO jurisdictions with the file name in the error.
2. **End-to-end grounding:** `LegalProvision` carries `sourceUrl/tema/
   fuenteVerificadaEn` from DB to `LegalContextProvider`; `AnalyzeContractUseCase`
   joins model citations back against the retrieved context (case-insensitive)
   and emits empty strings when there is no match, so the frontend never renders
   an unverifiable link. `GeminiAIProvider` filters `legal_basis` to references
   present in the supplied context. The objection-letter prompt appends
   `(fuente: <url>)` and instructs the model to stay traceable.
3. **Citation evaluation:** `evaluation/contracts.json` adds `expectedReferences`
   per clause (10 expected citations across lease/service high-risk clauses;
   employment and fair clauses expect none). `evaluate-providers.ts` loads the
   corpus, supplies LEASE=all arriendo, SERVICE=all consumo, EMPLOYMENT=none,
   and reports citation precision (cited ∈ context / cited) and recall
   (expected cited / expected) alongside HIGH precision/recall.
4. **Visible coverage:** `backend/data/legal/coverage.json` (generated by the
   loader) is mirrored to `frontend/src/data/legal-coverage.json` and rendered
   on a new `/coverage` page; `ClauseCard` renders references as external links
   with tema badge and verification date, and `Results` links to the coverage page.

## Consequences
- Positive: citations are auditable end-to-end (corpus → retrieval → prompt →
  UI → evaluation); hallucinated links are filtered before persistence.
- Negative: employment/laboral has no curated corpus yet (evaluation supplies
  empty context there); adding a domain requires a new corpus file + manifest
  entry + seed migration.
